# Hidronexo · braço hidráulico A-81 (garra G1 + base B1)

Simulador 3D e realidade aumentada do braço hidráulico A-81 com a **garra G1** e a **base B1** projetadas pelo grupo
(Projeto e Desenvolvimento de Produtos · DEP/UFTM).

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Simulador: arraste as seringas mestras, veja a água, as forças e o aperto da garra, e leve a engrenagem de A até B |
| `ar.html` | Realidade aumentada em tamanho real (Chrome no Android, Safari no iPhone) |
| `projeto.html` | O que o grupo mudou: números da garra G1 e da base B1 e imagens do CAD |
| `BracoRA.glb` / `BracoRA.usdz` | Modelo 3D animado |
| `BracoRA.glb.js` | Cópia do modelo para abrir o `index.html` direto do computador |
| `hidronexo.css`, `logo.png`, `favicon.png`, `apple-touch-icon.png` | Identidade visual Hidronexo: verde, bege e azul; fontes Press Start 2P e Space Mono (SIL OFL) |
| `preview.png`, `hero.jpg` | Imagem de compartilhamento e destaque da página do projeto |

Créditos: simulador e modelo do kit A-81 da disciplina (estrutura inspirada na skill teardown, licença MIT; three.js e model-viewer, licença MIT).
Garra G1 e base B1: geometria do projeto do grupo.
